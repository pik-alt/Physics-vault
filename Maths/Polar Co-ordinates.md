We can represent a point (x,y) with an angle and magnitude: $(r,\theta)$
$r^2 = x^2 + y^2, \theta=\arctan\left( \frac{y}{x} \right)$

Each multiple of $2\pi$ added onto an angle brings you back to the original angle.

It's also more convenient when working with polar co-ordinates to work with polar axes:

![[polar axes.png|372]]


Like in cartesian co-ordinates where x is the independent variable and you get the y from it, $\theta$ is the independent variable which you can get each r from.
If r ever goes negative, it just means it goes to the opposite quadrant.

## Common Differentiation Rules

$\frac{d}{dx}\ln(f(x)) = \frac{f'(x)}{f(x)}$

$\frac{d}{dx}a^x = a^x\ln x$

$\left( \frac{dy}{dx} \right)^{-1} = \frac{dx}{dy}$
