$P(A|B)$ = $P(A)$ given that $B$ has happened.

$P(A|B) = \frac{P(A\cap B)}{P(B)}$

also works in the inverse

$P(B|A) = \frac{P(A \cap B)}{P(A)}$

$\therefore \text{ } P(A\cap B) = P(A|B)P(B) = P(B|A)P(A)$


Bayes Theorem: $P(A|B) = P(B|A)\times \frac{P(A)}{P(B)}$

Often times, we do not know $P(B)$,  so we can use the above formula:
$P(B\cap A) = P(B|A)P(A)$

With the fact that:
$P(B) = P(B\cap A) + P(B\cap \bar{A})$

To get everything we need.
