**Newton's First Law: Force is required to change motion, not to maintain it**

The resistance of an object to change its state of motion is called **inertia**, which we quantify with Mass.

These Newton's laws only apply in inertial reference frames, which does not include ones in uniform circular motion.

**Newton's Second Law:  *$F=ma$***

You should use this in component form, splitting the acceleration into all of it's constituent component vectors.

**Newton's Third Law: If object 1 exerts a force onto object 2, object 2 exerts a force equal in magnitude but opposite in direction onto body 1**

It's key to remember that the action-reaction pairs act on different bodies.

If the Earth's gravity attracts a book down with a force, the book must exert a force equal in magnitude onto the Earth.

## Applied to Circular motion

We'll do this using [[Polar Vectors|polar co-ordinates]].

$a=\frac{v^2}{r}, = -\frac{v^2}{r}\underline{\hat{r}}$

$\therefore \mathbf{F} = -\frac{mv^2}{r}\hat{\underline{r}}$

You can also choose to write this as:
$\mathbf{F} = m \underline{a}$

$\therefore \mathbf{F} = m(a_{r}\hat{\underline{r}} + a_{\theta}\hat{\underline{\theta}})$

With the polar definitions of acceleration of:

$\underline{a} = (\ddot{r} -r \ddot{\theta})\hat{\underline{r}} + (2\dot{r}\ddot{\theta} +r \ddot{\theta})\hat{\underline{\theta}}$

and if the radius is constant, you can simplify this a lot more because then:

$\dot{r} = 0, \therefore \ddot{r} = 0$
