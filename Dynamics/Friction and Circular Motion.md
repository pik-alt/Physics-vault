
### Friction

There are two types of friction, static and dynamic friction, for when an object is stationary and in motion respectively.

If you keep applying a force on an object, eventually it will reach its maximum static friction, a resultant force will then occur and the object will begin to slide.
Once this happens, the object's static force is said to be in **limiting friction**.

Once the object starts moving, it experiences a dynamic friction force which is slightly less than the maximum static friction force that had to be overcome in order to get the object moving in the first place.

$\mu_{s} > \mu_{k}$

---
The force of friction on an object - for both static and dynamic friction - is directly proportional to the normal force.

$F=\mu N$

### Motion in a Vertical Circle

Because gravity is now in the picture, the velocity of a ball on a string being swung around vertically, for example, is no longer constant.

![[Circular motion forces.png|473]]

*The forces that act on a ball moving in circular motion*

Using [[Polar Vectors|polar vectors]], we can describe the motion of this a bit more clearly:

$F_{\theta} = mg\sin\theta$
$F_{r} = T-mg\cos\theta$


We can also use the acceleration in polar co-ordinates equation, with constant radius, which is:

$\mathbf{a} = -R\dot{\theta}^2 \hat{\mathbf{r}} +R \ddot{\theta} \mathbf{\hat{\theta}}$

Combining this with our above formulas for the radial and angular force, we can get:

$g\sin\theta = R \ddot{\theta}$

$\frac{T-mg\cos\theta}{m} = \frac{v^2}{R} \implies  T=m\left( \frac{v^2}{R} + g\cos\theta \right)$


---

The minimum speed that an object can go to remain in circular motion is the speed at which the tension just goes slack, which we can solve for by making T = 0.
