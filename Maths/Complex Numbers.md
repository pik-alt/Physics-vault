
We define the imaginary number $i$ as:

$i=\sqrt{ -1 }$

And every complex number as:

$z=a + bi \text{ where } a,b \in \mathbb{R}$

### Some definitions and functions

 A complex conjugate is $z^* = a-bi$
$i^2 = -1$

$|z| = \sqrt{ a^2 + b^2 }$


$z \times z^* = a^2 + b^2 = |z|^2$



You can write a complex number as $|z|(\cos\theta + i\sin\theta), \theta = \arctan\left( \frac{b}{a} \right)$

$arg(z) = \theta$

**Euler's Formula is $z=|z|e^{i \theta}$**


### Arithmetic with Complex Numbers

$z_{1} = a+bi$
$z_{2} = c+di$

$z_{1} \times z_{2} = (a+bi)(c-di)$
$\frac{z_{1}}{z_{2}} = \frac{z_{1}z_{2}^*}{z_{2}z_{2}^*} = \frac{z_{1}z_{2}^*}{|z_{2}|^2}$

Or

$|z_{1}z_{2}|=|z_{1}||z_{2}|$
$arg(z_{1}z_{2}) = arg(z_{1}) + arg(z_{2})$

$|\frac{z_{1}}{z_{2}}| = \frac{|z_{1}|}{|z_{2}|}$ 
$arg\left( \frac{z_{1}}{z_{2}} \right) = arg(z_{1}) - arg(z_{2})$


## De Moivre's Theorem

$(\cos\theta + i\sin\theta)^n = (\cos (n\theta) + i\sin(n\theta))$

## Roots & Hyperbolics

**The n'th root of z has n solutions**


$\sinh(\theta) = \frac{1}{2}(e^\theta - e^{-\theta})$

$\sin(i\theta) = \sinh(\theta)$
---

$\cosh(\theta) = \frac{1}{2}(e^\theta + e^{-\theta})$

$\cos(i\theta) = \cosh(\theta)$


---

$\tanh = \frac{\sinh}{\cosh}$

$\operatorname{ sech } = \frac{1}{\cosh}$

$\operatorname{csch}=\frac{1}{\sinh}$

$\coth = \frac{1}{\tanh} = \frac{\cosh}{\sinh}$
